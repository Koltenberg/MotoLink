# Состояние релиза

Подготовлена Moto Link 1.0.0 build 31 поверх подтверждённой на iPhone версии 0.4.21. Bundle ID сохраняется: `org.koltenberg.MotoLink`; пользовательские поездки не удаляются.

До установки проверить успешную Swift/Python-сборку, пакет IPA, SHA-256 и снимки реального симулятора. Результаты проверки относятся только к соответствующему коммиту. Установка и запуск на телефоне учитываются отдельно.

Полный разбор дорожных журналов и Apple HCI 04.10.2026 хранится локально у владельца. Нельзя объявлять CRC/No-Sync и supervision timeout физически устранёнными только по успеху CI. Новых диагностических профилей для этой сборки не требуется.

История исследований сохранена в `docs/`; прежние документы описывают соответствующие версии и не являются текущим списком обязательных действий владельца.
