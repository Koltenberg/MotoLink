# Проверка MotoLink 0.3

20 сентября 2026. Реальный первый обмен EX500G уже подтверждён журналами пользователя; новая версия ещё не проверена на устройстве.

| Проверка | Результат |
|---|---|
| Реальный EX500G, веб 0.1: 12 запросов, 12 ACK, 12 ответов | Подтверждено журналами |
| Веб 0.3: декодер, транспорт, последовательности, GPS, UI-entrypoint | 30 автоматических тестов прошли |
| Повторные подключения, ранние ответы, ACK без данных и отмена | Проверены на имитации Bluetooth |
| Источники профиля и точные длинные команды | 7 Python-проверок прошли |
| Валидатор будущего IPA | 8 Python-проверок прошли |
| Синтаксическая грамматика Swift, XML/plist и ссылки проекта | Проверены, см. ios/NATIVE_VALIDATION.json |
| SwiftPM-тесты | 7 подготовлено; не запускались без Swift |
| Xcode, simulator, физический iPhone | Сборка и запуск не выполнялись |
| Подпись IPA / установка | Не выполнялись |
| Веб-визуальная проверка в браузере | Не выполнена: загрузка Chromium недоступна |
| Реальная телеметрия 4A/45 EX500G, фон и переподключение iOS | Пока не подтверждены |

Реальные обезличенные кадры EX500G подтверждают восемь возможностей и напряжение 12,421875 В по унаследованной формуле. Наличие capability не доказывает конкретные значения остальных полей. Источники не содержат аппаратного 4A-образца; тесты арифметики синтетические.

Независимые чтения кода выявили и устранили ошибки отмены старой BLE-записи, ложного подтверждения потока повреждённым кадром, восстановления устаревшей копии поездки, двойного завершения, недосчёта GPS и повторного экрана экспорта. Это полезные проверки исходников, но не замена компиляции и физического теста.

Единую физическую сессию нужно проводить после подготовки и установки нативной сборки дома. Веб-версия также содержит полный автоматический сеанс, если нужен сбор через уже установленный Bluefy.

Предыдущая проверка сохранена в history/VALIDATION-0.1.md. Текущий источник истины по нативной проверке — ios/NATIVE_VALIDATION.json, по командам — research-v03/protocol-profile.json.
