# Архитектура Moto Link 0.4.7

SwiftUI → долгоживущий MotoLinkController из AppDelegate → MotorcycleBluetooth и RideRecorder. CoreBluetooth имеет restoration identifier и фоновой режим; CoreLocation записывает GPS отдельно. Отказ GPS или отсутствие интернета не останавливает BLE-запись.

Bluetooth intent, состояние подключения, готовность GATT и свежесть телеметрии разделены. Команды последовательны, ATT/ACK/измерения различаются. Повторы завершившихся ошибок используют backoff до 60 секунд без лимита количества. Уже ожидающий connect не отменяется по таймеру. Действующие notify сохраняются. Защита потока повторяет известный 08 однократно, не разрывает связь при других свежих пакетах и не отправляет неизвестный heartbeat. [Подробности](NATIVE_0.4.7.md).

RideRecorder сохраняет полный raw JSONL и компактный summary. Все raw события пишутся, fsync/atomic summary обычно раз в секунду, с принудительными границами жизненного цикла, завершения и экспорта. Запись выполняется в отдельной serial queue; ошибка checkpoint не выдаётся за успешный экспорт. SessionLogStore имеет ограниченный вращающийся журнал; файлы поездок не удаляются.

История группируется по месяцам и выводится по 30 поездок. Canvas рисует локальные точки GPS без MapKit/запросов Apple. Сегменты остаются раздельными. Пунктир пропуска не является дорогой и не увеличивает GPS-пробег. Старые дорожные оценки сохраняются в экспорте; неиспользуемый RoadEstimateController не вызывается интерфейсом. Встроенного дорожного графа для офлайн-прокладки маршрута пока нет.

Внешние источники нужны для исследования и сборки, не для записи поездки. У Moto Link нет аккаунта/облачного API. Подпись через Apple — отдельный этап установки. Ограничения iOS на Force Quit и восстановление после перезагрузки не отменяются background modes. Приложение также не может заставить мотоцикл включить Bluetooth-рекламу. [Источники](KAWASAKI_EXPANDED_RESEARCH.md).

Веб-клиент остаётся отдельным приложением с Web Bluetooth и IndexedDB. Его возможности в фоне/офлайн-перезапуске зависят от браузера и не равны нативному CoreBluetooth. Текущая установка и 92 проверки описаны в [результатах 0.4.7](NATIVE_0.4.7.md).
