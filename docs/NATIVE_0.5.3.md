# Moto Link 0.5.3 — пробег отдельно от путешествий

- Автоподключение снова является сохраняемым выбором. Выключение запрещает новые автоматические попытки, включая восстановление ожидающего подключения после запуска. Ручное подключение не включает переключатель обратно; действующая связь не обрывается от изменения настройки.
- Подробная запись поездок отдельная: после перехода с обязательной автоматики 0.5.2 она выключена, пока пользователь не включит её сам. Начать выбранное путешествие можно вручную. Работа телеметрии не зависит от записи.
- Компактный счётчик сохраняет итоговые расстояния по дням и выбранному Bluetooth-устройству, без координат и пакетов. Хранятся не более 400 дневных итогов на байк, старое сворачивается в общий результат. Удаление подробных поездок не удаляет этот отдельный счётчик.
- Расстояние — оценка по времени и свежей скорости мотоцикла, с переходом на прошедшую фильтры скорость GPS. Один интервал считается только один раз; устаревшие данные, длинные перерывы и время между перезапусками не достраиваются. Обороты и дроссель не используются для выдумывания отсутствующих километров. Источники скорости не являются калиброванным физическим одометром.
- GPS без подробной записи работает при подключённом байке и уже предоставленном разрешении. Во время выбранной подробной записи счётчик использует её GPS, в том числе после потери Bluetooth. Выключение счётчика сохраняется. При отсутствии обоих источников расстояние может быть недосчитано.
- Имеющееся показание/старая оценка гаража используется один раз при переходе. Новое подтверждение одометра задаёт точку отсчёта для следующих километров; старые поездки повторно не прибавляются. Другому Bluetooth-байку одометр текущего гаража не присваивается.
- Обслуживание поддерживает три настраиваемых порога в километрах: скоро, пора и просрочено. Старые фиксированные интервалы и диапазоны сохранены. Уведомления включаются пользователем, не требуют интернета и не повторяют уже отправленную стадию при каждом пакете или перезапуске.
- Компактный файл атомарно сохраняется вне Bluetooth-очереди, с объединением частых обновлений. Ошибка записи не стирает предыдущий файл и не сбрасывает несохранённые метры. Контрольная запись примерно раз в 10 секунд: аварийное завершение может потерять последний несохранённый хвост. Подробные журналы по-прежнему занимают место пропорционально длительности выбранных поездок; отдельный диагностический кэш ограничен примерно 50 МиБ.
- Настройка удержания экрана работает с живой приборной панелью без обязательной записи путешествия.

Фоновые соединения используют существующее восстановление Core Bluetooth. Это не обещание запуска при каждом зажигании независимо от iOS: принудительное закрытие приложения пользователем останавливает такой перезапуск до следующего открытия. Документация Apple: https://developer.apple.com/documentation/technotes/tn3115-bluetooth-state-restoration-app-relaunch-rules и https://developer.apple.com/library/archive/qa/qa1962/_index.html .

Проверки: регрессии настроек, интеграция скоростей/пропуски/смена источника/перезапуск/сворачивание дней, стадии обслуживания и защита от повторов. Интеграционный сценарий в симуляторе проверяет реальный компактный файл отдельно от подробного журнала. Это проверки логики и хранения, не доказательство отсутствия физических Bluetooth-обрывов.
