# Moto Link 0.4.13 — первое подключение и контекст обрыва

**0.4.13 build 18 собрана и установлена:** 28.09.2026 iLoader сообщил «Процесс выполнен». Владелец подтвердил запуск 0.4.13 и сохранность прежних поездок.

Версия включает системное восстановление Bluetooth из [0.4.12](NATIVE_0.4.12.md) и две дополнительные доработки по результатам проверки перед установкой:

- При выборе найденного мотоцикла настройка автоподключения сохраняется до первого запроса CoreBluetooth. Раньше при выключенной настройке запрос мог уйти без системного восстановления, а переключатель включался уже после него. Выбор не должен создавать дополнительный запрос или подключать прежний мотоцикл.
- При принятом событии отключения сохраняется краткий контекст: последнее значение RSSI и его возраст, давность пакетов и телеметрии, состояние приложения и соединения. Это пассивный снимок уже известных данных; он не вызывает дополнительного радиоопроса. Повторный callback завершения системного ожидания не должен выглядеть как второй физический обрыв.

Формат сохранённых поездок, гараж и команды Kawasaki не меняются. Для установки дополнительный диагностический профиль Apple не требуется. Специальный Bluetooth-профиль имеет смысл при повторном неожиданном обрыве, когда нужен пакетный разбор; прежний System Debug Profile предназначен для другой диагностики.

## Проверка

[CI37](https://github.com/Koltenberg/MotoLink/actions/runs/36349646470) на [исходниках 308e1c8](https://github.com/Koltenberg/MotoLink/commit/308e1c8adf90012ee0ecc30803b89e3a0b112851) завершён успешно с первой попытки. **168 Swift + 72 Python + 7 проверок профиля + 11 проверок очистки = 258**. Четыре новых теста проверяют первое подключение: настройка сохранена до запроса, запрос единственный, старый байк не выбирается, явное выключение соблюдается. Относительно установленной ранее 0.4.11 добавлено 32 Swift-теста переходов Bluetooth.

Скомпилированы simulator и iPhone arm64; приложение запущено на iPhone 17 / iOS 26.5, где также выполнена проверка нужного селектора нового Bluetooth delegate. Получены и просмотрены 11 реальных снимков: гараж, история, настройки, обслуживание, панель, светлая/тёмная тема, увеличенный текст и горизонтальное положение. Все маркеры готовности истинны, горизонтальное окно 874×402; блокирующих дефектов нет. Заголовок редактора обслуживания сокращается между полностью видимыми кнопками отмены и сохранения.

Неподписанная IPA: **3 605 454 байта**, SHA-256 `02160a538a7c7145cffefee07f1f0e67028c1c24d7add25dfd3101ba68c59675`. Локально повторно проверены хэш ZIP артефакта, IPA, версия/сборка, bundle `org.koltenberg.MotoLink`, платформа iOS/arm64, фоновые режимы, ресурсы шрифта и privacy manifest. Минимум iOS 16.0; отдельный запуск на iOS 16 не выполнен.

Обновление установлено поверх прежнего приложения с личной подписью. Приложение не удалялось, данные не очищались. Временный канал подписи после установки остановлен. Дорожная проверка именно 0.4.13 ещё не проведена; автоматические тесты и установка не доказывают устранение помех или непрерывную связь во всех условиях.
