# Moto Link 0.4.9 · build 14

Установлена 27.09.2026. Пользователь подтвердил запуск 0.4.9 и сохранность прежних поездок. Дорожная проверка этой версии ещё не выполнена.

## Помощник владельца
- Локальная карточка мотоцикла и введённый владельцем одометр; GPS-расстояния не подменяют показание одометра.
- Заправки: дата, одометр, литры, стоимость, полный бак; редактирование и удаление с подтверждением. Расход считается между полными баками с учётом промежуточных доливов, если внесены все заправки.
- Обслуживание: собственные интервалы по километрам и/или месяцам, отметка выполнения. Календарные напоминания работают локально после разрешения пользователя; пробег проверяется в приложении.
- Статистика завершённых поездок за неделю, месяц и всё время. Поездки с одинаковым введённым названием объединяются для сравнения времени, включая остановки.
- На главном экране крупные GPS-скорость и экспериментальная скорость байка. Разность показывается только при свежих сопоставимых измерениях. Автоматической калибровки нет. Анимация и дополнительные приборы свёрнуты.

## Связь и диагностика
- После 120 секунд ожидания пользователь может на остановке нажать «Повторить поиск». Сначала отменяется текущая попытка; новый поиск начинается лишь после callback завершения. Автоподключение сохраняется.
- Долгое ожидание CoreBluetooth само по себе не ошибка: pending connect не имеет встроенного таймаута. Непрерывно отменять его нельзя.
- BLE health содержит состояние радио, доступность защищённых данных, последнее RSSI и его возраст. Старое RSSI не выдаётся за текущее.
- Пассивно фиксируются изменения аудиомаршрута/прерывания текущей аудиосессии с ограничением объёма. Аудиосессия не активируется и не перенастраивается.
- Условия теста Sena/Watch/расположение телефона задаются владельцем. Автоматически доказать присутствие Sena либо активную радиосвязь Watch такими API нельзя. Условия сбрасываются после старта записи, вариант Sena и версия прошивки сохраняются.
- Команды байку, профиль и период запросов не менялись. Причина первого радиотаймаута не установлена.

## Основания и ограничения
Новый частный журнал 0.4.8: запись 40:24, поток телеметрии 37:06, один CBErrorDomain 6. Почти весь заезд в фоне с энергосбережением. GPS прекратился примерно за 53 секунды до Bluetooth timeout. Условия гарнитуры неизвестны; это не контролируемый A/B тест. Личные журналы и координаты не публикуются.

Источники: [Sena/Watch и границы диагностики](BLUETOOTH_COEXISTENCE_2026-09-27.md), [Kawasaki и изменения сторонних проектов](KAWASAKI_UPDATES_2026-09-27.md).

Новые тесты проверяют расчёт расхода, ввод/редактирование/удаление, календарные интервалы и повреждённые данные. Снимки демонстрационных данных компилируются только для симулятора. Успешная сборка не доказывает отсутствие будущих радиопотерь.
