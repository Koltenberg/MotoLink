# Аутентификация и данные Moto Link 0.4.7

В приложении нет собственного аккаунта, сервера входа, OAuth/JWT, API-ключа или облачной синхронизации поездок. Разрешения iOS, сопряжение Bluetooth, GitHub для сборки и Apple Account для установки — отдельные механизмы.

## Компоненты и поток

MotoLinkController создаётся через AppDelegate, удерживает MotorcycleBluetooth и RideRecorder, передаёт сырые события и измерения в локальную запись. Общее ядро содержит протокол и проверяемые политики восстановления/checkpoint.

1. iOS предоставляет разрешение Bluetooth, пользователь выбирает устройство. Фильтр по имени Kawasaki/UUID — обнаружение, не проверка подлинности владельца.
2. CoreBluetooth соединяется с peripheral, обнаруживает сервис, write-канал и три notify-характеристики. Существующие подписки сохраняются; недостающие включаются последовательно. Готовность требует все три канала.
3. Первая запись может вызвать системное сопряжение/PIN. Код вводится в iOS; приложение не хранит и не обрабатывает PIN самостоятельно. Фактические параметры шифрования BLE нельзя доказать чтением исходников приложения.
4. Фиксированная диагностика запрашивает идентификацию, возможности, данные и известный профиль потока. Строка MotoLink в команде 0B — имя клиента, не пароль.
5. ATT-подтверждение, протокольный ACK и измерение различаются. Команды сериализованы. Временные ошибки соединения повторяются без лимита попыток с паузой до 60 секунд; Stop и ошибки удалённого сопряжения обрабатываются отдельно.

Код: [контроллер](../ios/MotoLink/MotoLinkController.swift), [BLE](../ios/MotoLink/MotorcycleBluetooth.swift), [протокол](../core/MotoProtocol.swift), [восстановление потока](../core/BLEStreamRecovery.swift).

## Credentials и локальное хранение

- UserDefaults содержит UUID/имя выбранного peripheral, настройки, флаг возобновления телеметрии и UUID ранее проверенных устройств. Это не секреты. Своих auth-токенов и вызовов Keychain в нативном приложении нет; Bluetooth bond управляется iOS.
- Внутренний session UUID отсекает старые таймауты, идентичность CBPeripheral/характеристик — поздние callbacks. Этот UUID не credential.
- Полные RX/TX, время, идентификация и GPS могут содержать личные данные. Они хранятся на iPhone с защитой completeUntilFirstUserAuthentication, экспортируются пользователем через Share Sheet и не загружаются автоматически.
- История 0.4.7 рисует локальную схему без создания MapKit/MKDirections и без загрузки карт Apple. Старый RoadEstimateController пока остаётся неиспользуемым кодом; интерфейс его не создаёт. Старые оценки пути сохраняются в экспорте. Открытие истории не запрашивает GPS или дорожный сервис.

## Сборка и установка

Основной workflow имеет contents: read, checkout persist-credentials: false. Сборка отключает подпись и передаёт пустые identity/team. Apple Account, пароль и сертификат в unsigned IPA/репозитории не нужны. Ключи подключённого GitHub-плагина находятся вне приложения; их scope и срок жизни по репозиторию не определяются.

Личную подпись добавляет локальный установщик. Его сохранённый аккаунт — состояние установщика, не Moto Link. Пароли/OTP не записываются в репозиторий или журнал поездки. Использовавшийся временный транспорт передавал TLS только разрешённым хостам Apple, не расшифровывая содержимое; одноразовый закрытый ключ оставался локальным. После установки транспорт остановлен и ключ удалён. Это не постоянная зависимость приложения.
