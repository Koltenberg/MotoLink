# Moto Link Pixel

Derived from Pixelify Sans (copyright 2021 The Pixelify Sans Project Authors,
https://github.com/eifetx/Pixelify-Sans), under the accompanying SIL OFL 1.1.

Moto Link 0.4.7 uses a renamed static regular instance. Glyphs `5`, `Z/z`, `V/v`
and `Ы/ы` were redrawn on a pixel grid to distinguish five from S, Z from two,
and clarify V and the Cyrillic letter. Existing advance widths are retained.
All other glyphs and the license remain from the original font.

Rebuild with scripts/build-readable-font.py and fonttools 4.62.1 using the
original Pixelify Sans variable TTF as input. Numerical instruments use the
iOS system font separately for maximum legibility.
