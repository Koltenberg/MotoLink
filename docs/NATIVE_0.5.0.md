# Moto Link 0.5.0 — build 32

Обновление после установленной 0.4.21. Кандидат 1.0.0 build31 не устанавливался; его программные исправления включены в0.5.0 вместе с уточнениями владельца.

- GATT сохраняет поздние незавершённые операции и продолжает настройку по callback iOS. Service Changed может дать один ремонт до готовности, а также после исчерпанной подписки. Прерванный профиль затем продолжается; завершённый не повторяется. Физический линк не отменяется ради проверки.
- Устойчивый полный поток4A сбрасывает задержку после15сек независимо от числа расшифрованных полей. Быстрые реальные показания записываются до10Гц; дроссель до5Гц. Отображение и оформление не управляют Bluetooth.
- Журнал сохраняет миллисекунды и контрольные точки. Начальная сводка сохраняется до создания JSONL; восстановление учитывает записи после последней сводки и завершение поездки. Большие файлы и графики обрабатываются вне главного потока.
- Цветовые границы и максимум шкалы вводятся числами с точностью до единицы: для скорости, оборотов, двух температур, дросселя, передачи и напряжения. Скорость GPS/байка использует общую настройку. Неполный ввод не заменяет сохранённые значения; прежние настройки мигрируют.
- Ободья не рисуются поверх глушителя. Дым и свет заметнее; лёгкий ветер появляется при свежей скорости байка выше159км/ч. Это иллюстрация измеренных состояний, а не датчики света или выхлопа. В фоне, при устаревании, Reduce Motion и экономии заряда эффекты отключены.
- Сырые события, условия проверки и отдельные команды по умолчанию скрыты. Экспорт журнала доступен сразу. Тема следует iPhone либо выбирается светлой/тёмной.
- История получает свайпы удаления и закрепления, закреплённые поездки и свёрнутые старые группы. Данные закрепления сохраняются отдельно в малой сводке без переписывания большого журнала.
- Схема маршрута открывается на весь экран для масштаба, перемещения и поворота. Карта дорог — отдельный выбор пользователя. Дорожный вариант пропуска остаётся предположением: он не выдаётся за измеренный GPS и не меняет одометр.

## Проверка

Пакет0.5.0 и реальные снимки интерфейса ещё проходят общий macOS CI. До успеха сборки и просмотра снимков обновление на телефон не устанавливается. Bundle ID org.koltenberg.MotoLink остаётся прежним; исходные поездки не удаляются.

## Ограничение связи

Apple HCI за04.10 подтвердил реальные radio ConnectionTimeout0x08 без команды Disconnect приложения, ошибки No-Sync/CRC и supervision timeout1,25с. Программные исправления не доказывают устранения этих радиообрывов; публичный CoreBluetooth не предоставляет MotoLink изменение этого таймаута или мощности. [Аудит](BLE_IMPLEMENTATION_AUDIT_2026-10-04.md) отделяет подтверждённые исправления от неустановленной физической причины.
