# Moto Link 0.5.5 · build 39

Ручное подключение теперь сохраняет разрешение восстанавливать текущий сеанс независимо от переключателя автоматического подключения будущих сеансов. Явное отключение отзывает разрешение. Сохранённый OFF не меняется: при обычном новом запуске приложение самостоятельно не соединяется. После системного восстановления разрешение принимается только для того же выбранного устройства.

Это исправление отказа от восстановления после обрыва. Оно не меняет параметры радио и не подтверждает устранение первого физического таймаута. Профиль команд Kawasaki оставлен прежним. Личные журналы, координаты и идентификаторы устройств не публикуются.

Добавлена локальная Live Activity: имя байка, состояние связи, свежая скорость, время и расстояние записи. Включение доступно в настройках экрана. Карточка не отправляет Bluetooth/GPS-запросов. Устаревшая скорость скрывается. Начало карточки требует открытого приложения; существующая карточка может обновляться в фоне. Нужны iOS 16.2+ и разрешённые системой Live Activities. Карточка не предоставляет приложению дополнительное время фоновой работы.

В истории верхняя кнопка отправки включает выбор нескольких завершённых поездок. Выбранные записи экспортируются одним ZIP с полными JSONL. Текущая поездка исключается; большие журналы копируются потоково, упаковка работает вне очереди записи. Отдельная поездка также имеет верхнюю кнопку отправки. Ошибки экспорта видны в том же экране.

Проверки включают восстановление ручного сеанса, отмены и чистый запуск с OFF; свежесть карточки; распаковку ZIP с побайтовым сравнением журналов; экспорт через настоящий RideArchive в симуляторе; сохранность исходников при ошибках и очистке копий. Валидатор IPA проверяет вложенное расширение и совпадение версии/сборки с приложением. Результаты сборки и проверки на устройстве фиксируются отдельно: наличие этого файла не означает, что они уже пройдены.

Основание Live Activity: [ActivityKit](https://developer.apple.com/documentation/activitykit/displaying-live-data-with-live-activities). Локальная ZIP-упаковка: [NSFileCoordinator forUploading](https://developer.apple.com/documentation/foundation/nsfilecoordinator/readingoptions/foruploading).
