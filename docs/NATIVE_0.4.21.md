# Moto Link 0.4.21 — build 30

Предвыездной аудит изменений 0.4.13–0.4.20 обнаружил ошибки восстановления данных при сохранённом BLE-соединении. Это не доказательство устранения первого физического таймаута: следующий захват Apple Bluetooth по-прежнему нужен для разбора радиообрыва.

## Исправления

- Если два канала уведомлений теряют подписку почти одновременно, потеря второго теперь сохраняется, пока восстанавливается первый. Повторы последовательные, прежний лимит на канал не сбрасывается.
- Очередь первоначальных запросов ждёт восстановления подписок, затем продолжается. Раньше она могла очиститься, оставив проверку навсегда активной и заблокировав дальнейший опрос. Окно наблюдения также возобновляется после восстановления.
- Автоматическое начало поездки и восстановление подписки не обходят паузу 45 секунд и лимит одного повтора после ошибки начального профиля. Ручной запуск полной проверки остаётся отдельным действием пользователя.
- Разовая ошибка создания следующего файла диагностического журнала больше не оставляет закрытый рабочий файл. Следующее сохранение может восстановиться; событие, попавшее непосредственно на ошибку диска, всё ещё может быть потеряно, о чём приложение сообщает.
- При повторном сохранении завершения поездки уже записанная строка завершения не дублируется, если запись следующей строки или контрольное сохранение завершились ошибкой.
- При немедленном автоматическом начале следующей поездки пассивные наблюдатели получают новый идентификатор поездки, начальные снимки и отдельные лимиты событий.
- В исходные GPS-наблюдения добавлены точные времена замера и получения (`fixTimestampUnix`, `receivedAtUnix`), без изменения старого формата дат и чтения истории.
- Дополнены декларации уже используемых API таймеров и метаданных собственных файлов в PrivacyInfo.xcprivacy. Причины соответствуют [документации Apple](https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacyaccessedapitypes/nsprivacyaccessedapitype).

Новых команд мотоциклу, новых способов отключения, сетевых запросов или дополнительных запросов GPS нет. Профили Bluetooth и Location and Motion работают на уровне iOS; Moto Link их не включает и не подтверждает наличие HCI-файла.

## Оставшиеся границы

- Поздний успешный GATT-callback после 60-секундного прекращения настройки пока не возвращает состояние готовности: безопасное изменение требует отдельного моделирования актуальности объектов. В изученных журналах этот случай не подтверждён.
- Если процесс принудительно завершится между записью `finished` и заменой манифеста, восстановление может считать поездку незавершённой. Новая защита повторного сохранения относится к работающему процессу.
- Периодическая GPS-сводка формируется по поступлению callbacks; полное их отсутствие видно по исходному журналу и возрасту последнего callback при обрыве/завершении. Графики с 160 временными корзинами не служат измерителем причинности миллисекундных событий.
- На широком экране поездки подпись под мотоциклом частично перекрывается нижней кнопкой; основные показатели остаются видны. Это существующий косметический дефект, визуальная часть в 0.4.21 не изменялась.
