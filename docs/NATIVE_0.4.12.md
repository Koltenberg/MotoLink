# Moto Link 0.4.12 — восстановление Bluetooth

Статус: изменения готовятся и проверяются; сборка и установка пока не подтверждены. Последняя подтверждённая установленная версия — 0.4.11 build 16.

## Задача

После потери радиосвязи ожидание возвращения мотоцикла должно сохраняться и при приостановке приложения в фоне. Новое включение автоподключения во время завершения предыдущей отмены не должно теряться.

## Изменения

- На iOS 17 и новее используется системное автопереподключение CoreBluetooth, когда пользователь разрешил автоподключение. Пока повторным соединением управляет iOS, приложение не создаёт второй запрос и не отменяет системное ожидание по таймеру.
- Старый обработчик отключения и новый обработчик с `timestamp` / `isReconnecting` разделены между адаптерами для соответствующей версии iOS. Присутствие нужных Objective-C селекторов проверяется при запуске симулятора.
- На iOS 16 остаётся планировщик приложения с реальной паузой между завершившимися неудачными попытками. Уже выданный pending-запрос не имеет придуманного приложением срока годности.
- Ручная пауза и выключение автоподключения отменяют ожидание. Если пользователь разрешил подключение обратно до callback завершения отмены, новое намерение сохраняется отдельно и исполняется только после закрытия старого запроса.
- В диагностике различаются системное ожидание и попытка приложения. После возвращения соединения заново проверяются GATT-подписки и поток телеметрии; один значок Bluetooth не становится доказательством получения измерений.

## Границы

Это улучшение восстановления после разрыва, а не обещание устранить радиопотери. Публичные API центрального устройства CoreBluetooth не дают приложению команды для произвольного увеличения supervision timeout, изменения мощности радиопередатчика или управления Bluetooth-соединениями других приложений. Протокол запросов Kawasaki и профиль потока не меняются на основании догадок.

Личные маршруты и системные журналы Apple не входят в репозиторий. Сохранённые поездки и настройки остаются на телефоне; изменение не требует учётной записи или интернета для поездки.
