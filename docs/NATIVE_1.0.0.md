# Moto Link 1.0.0 — build 31

Изменения после 0.4.21: поздние GATT-ответы продолжают настройку; Service Changed допускает ограниченный ремонт до готовности подписки; устойчивый поток сбрасывает reconnect backoff. Готовые подписки и установленная связь не сбрасываются ради пробных keepalive-команд.

Журнал сохраняет миллисекунды, частые реальные обороты/скорость и дроссель. Контрольные точки позволяют восстановить незавершённую запись после сбоя; завершение из журнала корректно закрывает сессию. Ручное начало возможно без GPS. Чтение больших файлов и вычисление графиков не блокируют запись и интерфейс.

Неизменившиеся возможности не обнуляют показания. Симулятор проверяет графики с несколькими линиями и пропуском данных в портретном и горизонтальном режимах.

Сохранены гараж, редактирование/удаление истории, заправки без известных литров, интервалы обслуживания, темы и пиксельный текст. Bundle ID прежний; история при обновлении сохраняется.

Автоматические результаты сборки и установки дополняются после фактического выполнения. Непрерывная радиосвязь не подтверждается номером версии: анализ HCI выявил внешние ошибки приёма и timeout периферии, без команды приложения на разрыв.
