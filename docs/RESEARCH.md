# Найденные проекты и полезные результаты

Проверка 20 сентября 2026. Это исследование исходников, не полевой тест EX500G.

| Проект | Что даёт | Ограничение |
|---|---|---|
| [Zen3515 Kawasaki BLE](https://github.com/Zen3515/homeassistant-kawasaki-rideology-ble) | Полный Python-клиент, запросы, capability, парсеры и fixtures; основной источник | Проверен автором на Z500 ER500F, работает внутри Home Assistant |
| [Wazeology](https://github.com/agstrc/wazeology) | Независимое подтверждение UUID/команд, последовательная очередь, handshake | Android-патч Waze для TFT, по README испытан на Z900 SE; не навигация для стандартной LCD Ninja 500 |
| [Mobile BLE proxy](https://github.com/Zen3515/homeassistant-mobile-ble-proxy) | Android-телефон как BLE-посредник для Home Assistant | Не самостоятельное приложение для нашего iPhone; GPL-3.0, код не переносили |
| [rideology2gpx](https://github.com/jbokser/rideology2gpx) | Конвертация выгруженных логов штатного приложения в GPX | Не подключается к байку вместо RIDEOLOGY; GPL-3.0, код не переносили |
| [kawasaki-grapher](https://github.com/biwabel/kawasaki-grapher) | Анализ поездок из экспорта штатного приложения | R-пакет, не мобильный BLE-клиент |
| [Bluefy](https://apps.apple.com/ru/app/bluefy-web-ble-browser/id1492822055) | Выполнение нашего Web Bluetooth интерфейса на iPhone без сборки собственного iOS-пакета | Нужен HTTPS; совместимость нашей страницы/байка ещё требует теста; не заявляем фоновый автологгер |

Публичный поиск не дал готовой проверенной самостоятельной iOS-замены для EX500G.
Это результат ограниченного поиска, а не утверждение, что такой программы нигде нет.

## Самые полезные открытия

Рекламируемый сервис 99EB13AC… и рабочий сервис 92FAEC07… различаются. Все четыре
характеристики рабочего сервиса совпали в пользовательских скриншотах и обоих
проектах. Короткие запросы можно реализовать без входа в аккаунт RIDEOLOGY;
сопряжение мотоцикла остаётся самостоятельным шагом.

Валидный 0x40 возвращает набор и схемы показателей. Это позволяет сделать
приложение под реальные возможности байка и позже добавлять другие модели.
Нельзя заранее обещать топливо, одометр или запас хода: в публичном профиле
Z500 эти поля не поддержаны. Его восемь доступных полей — только ориентир.

Наши старые логи содержат соединение и чтение нескольких характеристик FEF5,
но не полноценные ответы телеметрии 92FA. Значения 0D и F400 не считаем вольтами,
температурой или оборотами. Для нового приложения нужна запись model/capability
ответов из правильного сервиса.

условия и уведомления включены в архив. Материалы GPL-проектов использованы только
как указатели на альтернативы, исходники в приложение не копировались.
