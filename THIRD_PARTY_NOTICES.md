# Происхождение

Схемы UUID, коротких запросов и capability bitfields перенесены с изменениями из
Zen3515/homeassistant-kawasaki-rideology-ble, commit
06a0f61681e119f5e5dd9a793d8a61c891a020f8.
Источник: https://github.com/Zen3515/homeassistant-kawasaki-rideology-ble
Лицензия Apache License 2.0, полный текст LICENSES/Apache-2.0.txt.

Изменения MotoLink: Swift/JavaScript-перенос выбранных схем; строгий список
запросов; проверки кадров; сохранение unknown вместо угадывания значений;
жизненный цикл подключения; русский диагностический интерфейс и экспорт.
Копии в reference/upstream сохранены без изменений с исходной лицензией.

Wazeology использован для независимой проверки протокола. Исходные Java-файлы
сохранены в research-v03/wazeology как материалы исследования, с исходной
лицензией Apache-2.0 и закреплённой ревизией в SOURCE.json.
В приложение Java-код не включён; фиксированные формы запросов сверены с ним.
Код сторонних GPL-проектов в продукт не включён.

MotoLink — неофициальный проект. Kawasaki, RIDEOLOGY, Apple и Bluefy упомянуты
для идентификации совместимости; их логотипы и фирменное оформление не используются.
